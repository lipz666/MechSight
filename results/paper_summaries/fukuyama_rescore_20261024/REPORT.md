# FukuyamaBench 评价口径修复与历史结果重算（2026-10-24）

- 代码：`develop/fukuyama_metrics.py`
- 测试：`develop/tests/test_fukuyama_metrics.py`
- 重算脚本：`experiments/fukuyama_rescore/rescore.py`
- 数据：`summary.json`（汇总）、`rows.jsonl`（逐条运行）

## 1. 为什么要改

FukuyamaBench 只记录中间态，不记录箭头。原评分器 `score_external_benchmark.py` 逐步比较成键、断键、键级和电荷的差分，所以下面两种情况都会被判错，尽管它们不是化学错误：

- **粒度**：把一个 GT 步拆成两步，会多出中间态的电荷变化，事件完全相同也通不过 L1。例如 B024：模型的事件和 GT 一模一样，只是把 GT 第 0 步拆成 3 步，旧口径的 L1 和仅键 L1 都判错。
- **共振**：离域中间体的电荷或 π 键画在哪里，只是表示上的选择，但状态差分会把它记成变化。

## 2. 新口径

**主指标一：σ-L1。** 整条路径上 σ 键的形成和断裂（多重集，H 标签匿名）与 GT 一致。

- 不看键级和电荷，所以与共振写法无关。
- 只比较多重集，所以与分步粒度无关。

**主指标二：GT 中间态按序命中**（`intermediates_in_order`，带共振归一化）。

- GT 的每个中间态和终态，都要按顺序出现在预测状态序列里。
- 预测可以比 GT 更细（多经过一些状态），但不能更粗。合并 GT 的两步等于声称协同，算错。
- 两个状态"相同"按 GT 中的每个分子逐个比较，要求：原子集合相同、σ 连接相同、每个重原子的 H 数相同（显式 H 和记录的 Hcount 合并计算）、分子净电荷相同。满足这四条的两个 Lewis 结构，只差 π 电子或孤对的位置，就是共振式。
- 质子位置不同（互变异构）、净电荷不同，都算不同。
- 只出现在预测里的分子（尚未加入的试剂、被 GT 丢弃的副产物）忽略。

**辅助指标：**

- σ-L2：σ-L1，再加上因果顺序不倒退。更细的路径通过，重排的不通过。注意：它也会放过"更粗"的路径。
- 严格按序命中：在主指标二的基础上，再要求键级和重原子电荷完全一致。只用来衡量共振归一化起了多大作用。
- 终态匹配，以及旧口径的 L1/L2/L3。

**验证：**

- **GT 自洽：** 60/60 题把 GT 逐步变化施加到累积初态上，宽松和严格两种模式下都能按序重现全部中间态。60/60 题 GT 第一个中间态包含在累积初态中。
- **单元测试 9 项：**
  - 共振式在归一化下相同，在严格模式下不同；互变异构和净电荷差异一定判为不同。
  - 显式 H 与 Hcount 等价；只出现在预测里的分子被忽略。
  - 更细的路径通过；重排的路径 σ-L1 通过、σ-L2 不通过；H 标签匿名。
- **反向核查：** 有 16 条运行旧 L1 判对、新的按序指标判错，其旧 L2 全部判错，即事件集合对、顺序错。新指标要求顺序，这是一致的。
- **逐例核查：** σ-L1 判对、按序判错的典型例子：
  - A059：N₂ 离去与 Wolff 重排被合并成一步。
  - C075：跳过了 Rh–羰基叶立德中间体。

  这些都是真实的"协同还是分步"差异，新指标判错是对的。

## 4. 怎么读

1. **旧口径大约低估了一半。** Agent + 23 Skill 从 20.0% 变为 35.8%（按序命中）和 51.7%（σ-L1）。按序命中但旧 L1 判错的有 24 条，其中 13 条只是比 GT 更细，16 条要靠共振归一化才判对（两类有重叠）。Set C 不再是 0%。
2. **两个主指标衡量的是不同层面。**
   - σ-L1：成键/断键的事件对不对。
   - 按序命中：经过的中间体对不对，包括顺序、协同还是分步、质子在哪、电荷在哪个分子上。

   两者的差距（23 Skill 组有 21 条 σ 对、中间体错）主要来自三类：顺序错（σ-L2 失败）、把 GT 的分步写成协同、电荷或质子归属不同。
3. **P2/P3 的结论不变，而且更清楚了。**
   - oracle 提示把 σ-L1 从 50% 提到 79%（+29pp，CI [+8, +50]），但按序命中没有提升（−8pp，CI [−21, 0]）。
   - 知道了哪些瞬态键，模型能把事件写全，但顺序、协同/分步、质子归属仍然是错的。
   - "提出隐藏事件"和"把它们排成正确的中间体序列"是两个独立的瓶颈。
4. **Skill 数量：** 79 vs 23 Skill 的配对差值为 σ-L1 +3.3pp [−2.5, +9.2]、按序命中 +2.5pp [−5.0, +10.0]，都不显著。
5. **正向模式**（不给目标态）在两个主指标上都明显更低：30.0% / 23.3%。

## 5. 限制

- "相同 σ + 相同 H + 相同分子净电荷即共振等价"是有意的宽松判定。它不检查该共振式是否是合理的主要贡献者，也不检查价态是否合法。严格版本一并报告，用于对照。
- 按序命中依赖 GT 的中间态划分。GT 若把协同过程写成分步（如 A059 的 Wolff 重排），协同的预测会被判错；这类判定最终需要专家复核。
- 重放用的是本地运行时 `apply_action`，与原 Agent 运行时的成键质子电荷处理可能不同。分子净电荷的计算包含显式 H 的电荷，以抵消这种差异。
