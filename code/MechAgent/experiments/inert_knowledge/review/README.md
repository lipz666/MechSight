# 隐藏中间体核验工具

启动：

```bash
python3 MechAgent/experiments/inert_knowledge/review/serve.py 8765
```

然后用浏览器打开 http://127.0.0.1:8765 。在右上角填写核验人缩写，标注会自动保存到 `annotations.jsonl`（只追加，不覆盖）；也可以点"导出 JSON"另存一份。

快捷键：`j` / `k` 翻页，`1`–`3` 选择判定。

| 任务 | 条目数 | 对应实验 | 问题 |
|---|---|---|---|
| 匹配核验 | 67 | C-4 | 模型在自由文本里列出的中间体，与参考机理中的隐藏中间体是否确为同一个 |
| 中间体分类 | 90 | C-3 | 隐藏中间体的类别（可多选），以及参考机理中该步骤是否合理 |
| 同系物检查 | 20 | KS-3 | 在远端碳上加一个甲基后，机理是否不变 |

说明：
- 为了保持盲评，页面不显示模型在可执行格式里是否用到了该事件。
- 分类任务的 AI 预标注默认折叠，建议先自己判断再展开查看。
- 机理帧使用 `develop/viz/render_rdkit.py` 绘制：下一步断开的键标为浅红，下一步形成的键画成绿色虚线，隐藏窗口（隐藏键存在期间）用绿框标出。

重新生成数据：先运行 `prelabel.py`（需要设置 `OPENAI_API_KEY`），再运行 `build.py`。
